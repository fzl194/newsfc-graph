# 图谱边定义（全景）

> **定稿 v1（规范 0.21.0，2026-08-18）**。本文件是全图层**边的权威定义**：关系清单、提取规则、校验规则、实测基线。
> 数据基线：UDG/UNC 20.15.2 全量资产（命令层 v0.20.0、特性层 v0.21.0 重建后实测）。

## 0. 总则：边与引用的边界

- **边只活在 `## 边` 章节**，格式 `- 关系: [[目标逻辑ID]]`，一行可多目标（`- 复用步骤: [[A]], [[B]]`）。
- **平台解析是关系名开放的**（`graph-asset-platform/backend/app/edges.py::parse_edges`）：任意关系名都建边，按 `(from_id, relation, to)` 去重。**新增边类型无需改平台代码**；前端按关系名自动分组。
- **正文里的 `[[ID]]` 是 Agent 跳转引用，不建边**（`rewrite_doc_refs` 把原文超链接改写而来；例外：特性层命令引用除正文改写外**同步落「使用命令」边**，见 §2）。
- 目标一律用三段式逻辑 ID `[[{nf}@{Type}@{local}]]`，版本动态解析（Task 层资产本身无版本，v0.19.0）。
- **通用排除项**（全文锚定扫描统一口径）：代码块（``` 围栏内）、TOC 行、自身（防自引用）；**存在性校验内建于提取**（目标不在合法集即丢弃，manifest 记 dropped）。
- **构建顺序**（平台 pipeline 编排依据）：命令层两趟（名集→构建）→ ConfigObject 读 Command 产物；特性层 **licenses 先于 features**（特性侧所需License 校验需 License 已建，v0.21.0）；features 读 Command 索引 + 同批特性码。
