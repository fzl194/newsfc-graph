# CR-20260820-001-命令多目录输入

## 场景
新产品文档把 MML 命令拆分到多个目录（多个命令分册）。平台「自动抽取」原来只能选一个命令源目录（用户需求 2026-08-20：已有功能不变，仅命令抽取支持多目录）。

## 规范现状
`command/scripts/build_commands.py` 的 `--mml-dir` 为单值参数；参见边两趟校验的**全量命令名集**只在单次运行内收集——分多次跑多目录会因名集不全丢参见边。

## 当时怎么处理的
（本次即为修复）`--mml-dir` 改 `action="append"` 可重复传参：多目录**单次构建**传入（rglob 并集按 resolved 去重，目录重叠不重复建）；category_path 取"包含该文件的第一个源目录"的相对路径。单目录用法完全兼容。回归测试 `MultiMmlDirsTests`（跨目录参见边为核心断言）。

## 建议的规范补丁
- SKILL.md 输入表 `--mml-dir` 注明可重复；升版本 0.23.0 + CHANGELOG
- 平台侧同步拷贝（字节一致）；MineIn.dirs 的 mml 角色归一化为列表；前端命令角色多选

## 影响范围
仅命令层构建器输入能力，无资产格式/边规则变化；单目录场景行为不变（append 单值等价）。
