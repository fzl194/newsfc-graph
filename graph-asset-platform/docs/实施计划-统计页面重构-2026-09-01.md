# 实施计划：统计页面重构（三视图统计）

> 日期：2026-09-01 ｜ 需求权威：《图谱平台统计页面需求说明书（外部Agent版）.md》v1.0（仓库根目录）
> 状态：已实施完成（本文档为落地记录：实现决策、端点清单、验收映射、部署注意事项）

## 1. 背景与结果

统计页从"按 UI 层聚合的内存索引卡片"重构为**三 Tab 统计视图**（命令图谱 / 特性图谱 / 业务图谱），
数据源改为 platform.db 只读 SQL 聚合（objects/edges + 8 张 AIMML 历史规则表），支持多维筛选与
CSV/Excel/Markdown 导出。旧 `GET /api/v1/stats` 保留（AppHeader 头部计数 / LayerNav 下拉 /
UploadView 提示仍依赖）。

## 2. 实现决策（用户授权开发 Agent 自主拍板，2026-09-01）

| 决策点 | 结论 | 依据 |
|---|---|---|
| 8 张规则表建表 | db.py v11 幂等 CREATE（DDL 与需求书 §9 逐字一致）+ 索引 | 本地库无表；内网由 dump 脚本灌数 |
| 旧 /stats 端点 | **保留不动** | App.vue/AppHeader/LayerNav/UploadView 四处依赖 |
| 新端点前缀 | `/api/v1/stats/*`（auth 兜底 = frontend 权限） | 与旧端点并列；导出避开 `/api/v1/export` 的 upload 权限分支 |
| A5 被引用入边 | **跨图谱入边**：to 指向本图谱节点 且 from 不属本图谱（NOT EXISTS）；edges.to 无版本列 → EXISTS 按 id 去重多版本目标 | 需求书 A5 期望 79,051 = 使用命令 77,166 + 对应命令 1,885，恰为跨图谱构成；图谱内部边已在 A4 出边计（否则双计）；按 id 直接 JOIN 会按目标版本数放大 |
| 双向合并 | SQL 按 relation 原值计数 → Python 成对取 MAX（五对） | §7.1（不可先合组再 COUNT——那是相加） |
| Excel 导出 | stdlib zipfile 手写最小 OOXML（inlineStr）真 .xlsx，免新依赖 | 依赖零增量；SpreadsheetML(.xls) 会有格式不匹配告警，弃 |
| 导出触发 | 后端生成（与视图端点同参数同数据）；前端 fetch 带 KEY → blob → a[download] | 单一口径；直接导航无法带 X-API-Key |
| 网元筛选 | objects 系与规则表系各自原生命名直筛；UPCF 筛选命中 objects `nf IN ('PCF','UPCF')` + 规则表 `='UPCF'`；展示层 PCF 统一显示 UPCF | §6.1/§7.4；语法表 NE_TYPE 自有命名（UEG-M 等），别名册本期不做 |
| 逻辑网元 | 命令集 = 所选(网元×版本)下 LOGICAL_NE_CMD_T 的 COMMAND_NAME 并集，仅作用 B1/B2 | §6.2 |
| 版本 | 筛选/分组恒用国内号；overseas 开关仅改展示（多海外版 `/` 并列，映射不到显原值） | §6.3/§7.2 |
| B1 双口径 | 卡片显全局 DISTINCT；另给"分组求和口径"（同命令跨 (NE,版本) 重复计） | Case 1 全局 35,051 ≠ §5.1 分组求和 |
| 下钻分页 | GROUP BY 结果 ≤ 数百行，不分页，前端排序 | KISS |
| TelemetrySection | 保留页面底部（打点统计不在本次重构范围） | 不删既有能力 |
| 图表 | 本期不做（需求只要求卡片+明细表+导出） | YAGNI |

## 6. 部署注意（内网）

1. `git pull` + 重启即完成 schema v11（幂等建 8 张空表；platform.db 其余不动）。
2. 8 张 B_AI_* 表数据由内网 GaussDB 导出脚本灌入：
   `AIMML历史图谱/db_tool/dump_rule_tables_to_platform.py`（需求书配套，内网已具备；
   若 platform.db 已含数据则只需重启）。**未灌数时**统计页命令图谱的命令/参数/五类规则
   指标为 0，页面顶部会出现"规则表未导入"提示条。
3. 运行环境需 SQLite ≥ 3.38（`json_extract` 提取 feature_code/license_code；
   Python 3.11+ 自带的 sqlite 均满足）。
4. 验收：对需求书 §11 各 Case SQL 在内网库复跑，页面/导出数字应逐一一致
   （A5 口径差异见 §2 决策表——跨图谱入边）。

## 7. 已知边界

- 语法规则表 NE_TYPE 自有命名（UEG-M/vSE2980_4U…）与 objects.nf 的别名映射本期不做
  （需求书 §9.1："本表为主，后续可建别名字典"）——B1/B2 下钻按表内命名展示。
- 方案筛选（solution）只收窄业务图谱"域→场景→方案"下钻表，不反推任务边计数。
- 导出 xlsx 为最小 OOXML（无样式），多 Sheet = 汇总节 + 各明细节。
