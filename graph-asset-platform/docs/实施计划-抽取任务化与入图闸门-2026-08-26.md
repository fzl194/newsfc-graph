## 手工验收清单（内网真实归档）

1. 解压一个产品文档包（流程不变）→ 抽取页选包，目标默认=包名；
2. 改目标网元（如 UDG→AMF）→ locate 推荐随目标变；抽 cmd → 门禁报告纯新增 → 覆盖 →
   图谱浏览查 `AMF@MMLCommand@*`；
3. 同包再抽（目标 UDG，另一目录）→ 分次累积 → 门禁报告同目标重复情况；
4. 未抽命令直接抽 feature → 400 缺 Command+License；补齐后抽 feature → 门禁报告含
   Command 层修改（自动重跑补引用）；
5. 历史任务「移除产出」→ 新增文件进回收站、覆盖文件还原；改过的不动（跳过提示）；
6. awaiting 状态重启后端 → 弹窗仍在可确认/撤销；processing 中重启 → 任务 failed+沙箱被清。
