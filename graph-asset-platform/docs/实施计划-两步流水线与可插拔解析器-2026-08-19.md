## 1. 目标形态

```
上传页签（权限 upload；挖掘二次校验 assets）
├─ 指定层上传（不动）
├─ 产品文档解压（原"产品文档导入"瘦身）
│    nf + version + .hdx/.hwics → 解压 → 转换 → md 留存 + bundle.json
│    进度步骤：解压 → 转换 → 留存（无构建）
│    历史任务（kind=product_doc_extract）
└─ 自动抽取（新）
     ① 已解压包列表（仅 status=done；nf/版本/上传时间/md 数）
     ② 定位确认：三类源目录 = 自动推荐 + 候选下拉人工改选（只能从服务端枚举候选中选）
     ③ 抽取配置：范围四勾选（默认全选；依赖强制联动）+ 模式下拉（5GC产品文档）+ 覆盖重建勾选
     ④ 确认 → 后台 job（kind=product_doc_mine）→ 分步进度 → 完成摘要
     历史任务（kind=product_doc_mine）

存储：platform-data/output/{nf}_{version}/   ← md 树 + bundle.json（html/原件不落此处，解压中间态在 .pdoc_ 临时目录随任务结束删除）
模式：backend/app/pipeline/modes/ 注册表（新增模式=新文件+注册一行，前端下拉自动出现）
```
